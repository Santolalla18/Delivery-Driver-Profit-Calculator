# Delivery-Driver-Profit-Calculator
Learned  how to build a tool for delivery drivers in the state of Florida that don’t know what they earn by accounting for self employed tax rate, car devaluation, mileage consumption, dead driving time and gas consumption. 

# Instructions
Open command propmt, input the folder directory and run it with 'python GUI_pc.py'.
Input your values.
